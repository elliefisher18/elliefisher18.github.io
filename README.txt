ELLIE FISHER — PORTFOLIO STARTER

HOW TO PREVIEW
1. Unzip this folder.
2. Open index.html in your browser.
3. Edit index.html and style.css in Sublime Text.

FILES
- index.html: the single-page portfolio
- style.css: the portfolio styles
- assets/: Ellie’s photo and project images
- projects/campuskind/: the original CampusKind Donations website and its local assets
- projects/csszengarden/: the submitted CSS Zen Garden website and stylesheet

PROJECT PREVIEWS
- Outfit Planner uses an embedded preview of the live website and links to the full site.
- CampusKind Donations uses Ellie’s actual logo, clothing images, and donation map; click it to open the included website.
- CSS Zen Garden opens the included project copy. A local file URL such as file:///Users/... only works on the computer where that file exists, so this portfolio uses the uploaded project files bundled here instead.
